## Terminal Execution Preference
- **Condition**: Whenever there is a need to run a terminal command (like npm install, git commands, etc.).
- **Action**: Do NOT run the command automatically using tools. Instead, provide the command as a text/code block so the user can copy-paste and run it themselves. Only run commands if explicitly instructed to do so.

</RULE[user_global]>
